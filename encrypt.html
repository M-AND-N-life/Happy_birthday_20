Notebook photo encryptor

Runs only on this computer. Nothing is uploaded anywhere. Your password is never saved.

1Choose the photos

Select all photos at once. Use the arrows to set the order: photos 1 and 2 go on the first photo page, 3 and 4 on the next, and so on.

2Song (optional)

Pick an mp3 to encrypt it too (saved as song.js). Or skip this and put a file named song.mp3 in the assets folder yourself.

3Password

4Photo size

Photos are resized (longest side in pixels) and re-saved as JPEG. This keeps the site fast and also removes hidden data such as GPS location.

5Encrypt and save

Done. Now save the files into the assets folder of your notebook:

"Save into a folder" works in Chrome and Edge: pick the notebook folder (or its assets folder). "Download" puts the files in your Downloads folder; then move them into notebook/assets/, replacing the old ones. If your browser asks to allow multiple downloads, say yes.

Keep your original photos in the originals folder (or anywhere outside the notebook folder). Only upload the files in assets/ plus index.html. If an original photo is ever pushed to GitHub, deleting it later does not remove it from the repository history.
